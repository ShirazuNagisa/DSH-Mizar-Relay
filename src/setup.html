连接设备Connect your devices

  1. 电脑：打开 AGI Mizar → 设置 → 服务器 → 自建服务器，填上面的地址和服务器 PIN。 Computer: open AGI Mizar → Settings → Server → Self-hosted, then enter the address above and the server PIN.
  2. 手机：DSH-Mizar → 新手教程或设置 → 服务器 → 自建服务器，填同样的地址和 PIN。 Phone: DSH-Mizar → guide or Settings → Server → Self-hosted, with the same address and PIN.
  3. 配对：在手机的「连接你的电脑」里选这台电脑，输入电脑上显示的 6 位配对码。 Pair: in the phone's "Connect your computer", pick the computer and type the six-character code it shows.

手机和电脑都要先装好 App。电脑端在 GitHub Releases 下载。 Both apps must be installed first. The desktop app is on GitHub Releases.

排错Troubleshooting

  • 域名必须解析到这台服务器，80 和 443 都要放行；证书由 Caddy 自动申请。 The domain must point at this server and both ports 80 and 443 must be open; Caddy obtains the certificate.
  • 证书日志：journalctl -u caddy -n 50；中继日志：journalctl -u dsh-mizar-relay -n 50。 Certificate log: journalctl -u caddy -n 50; relay log: journalctl -u dsh-mizar-relay -n 50.
  • 重置 PIN 或更新 token：在安装目录运行 sudo ./install.sh --rotate-pin 或 --rotate-update-token。 Rotate the PIN or update token: run sudo ./install.sh --rotate-pin or --rotate-update-token in the install directory.
  • 更新失败后会保留上一版并自动回滚；手动重试：sudo /opt/dsh-mizar-relay/update.sh --apply。 A failed update keeps the previous version and rolls back; retry by hand with sudo /opt/dsh-mizar-relay/update.sh --apply.
自建服务器不依赖官方服务器；安装、更新与排错都在本机完成。 Self-hosting does not depend on the official server; install, update and debugging all happen here.
